# Hotel Room Booking System

## Project Description
A Java-based console application for managing hotel room bookings.

## Features
- View Rooms
- Book Rooms
- Search Available Rooms
- Check Out and Generate Bill
- Sort Rooms by Price
- Save and Load Data

## Technologies Used
- Java
- ArrayList
- HashMap
- Searching
- Selection Sort
- File Handling

## How to Run
1. Open the project in VS Code.
2. Compile Main.java.
3. Run the Main class.
4. Select an option from the menu.

## Default Room Details
101 - Single - 1500
102 - Double - 2500
103 - Suite - 5000
